# multi 文档级检索 + 按问题类型选块

日期：2026-11-02

## 方案

多主题问题启用独立检索路径，默认关闭，`ask --multi-doc-select` 或评测 `type=multi` 时启用：

1. 每个子问题先做正文召回，取 top3 文档；
2. 再用标题 BM25 找 top2 文档，标题分数接近时优先最新年份；
3. 同一文档内按问题意图选块：险种 / 标准 / 期限 / 条件 / 对象 / 项目；
4. 每个子问题至少保留一个高置信块，再用原问题统一精排；
5. 多主题模式最终给 6 条证据，比默认 5 条多 1 条，避免两个主题互相挤掉。

门控：原始问题至少 2 个问号、子问题主题不同、子问题命中不同政策名。
同一政策的追问（如“在职人才入户 + 社保暂停”）仍走旧路径，避免回归。

## 结果

25 条 multi，v3 strict gold（57 条要点）：

| 口径 | 要点覆盖 | 整题全中 |
|---|---:|---:|
| 旧检索路径 | 49/57（85.96%） | 18/25（72.00%） |
| 文档级选块 | 56/57（98.25%） | 24/25（96.00%） |
| 文档级选块 + 人工校正 Q7 误判 | 57/57（100.00%） | 25/25（100.00%） |

目标缺口 Q5、Q13、Q22、Q24、Q25 在最终运行中全部覆盖。Q13 通过“资格类问题补补贴对象/条件块”修复。

## 回归检查

- 8 条“多问号 fact”题：旧路径 30/30，新路径类型门控后仍为 30/30。
- 同一政策追问（Q6/Q12/Q18/Q19 等）通过门控走旧路径。
- 逐题结论仍有 LLM 子问题拆分和 L1 裁判方差；这不是确定性提升，需保留旧路径可回退。

## 剩余问题

- Q7「之前不补发」：L1 判 false，但回答已写“企业未参保人员：之前不补发”，属于裁判误判。
- 25 条 multi 的真实要点缺口已清零；后续应转入引用/展示/其他功能，不再继续调 multi 检索。

## 产物

- `app/retrieve/doc_select.py`：问题意图识别、同标题最新版本、文档内选块
- `app/retrieve/hybrid.py`：标题 BM25、标题候选
- `app/pipeline.py`：多主题文档级检索路径与门控
- `data/eval_gold.multi25.jsonl`：25 条 multi strict 子集
- `data/eval_gold.fact_multi8.jsonl`：8 条多问号 fact 回归子集
